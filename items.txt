#6 USB PD Trigger Module

Description
Reviews
This USB PD trigger module allows you to request specific voltages (5V, 9V, 12V, 15V and 20V) from a USB-PD power supply. In addition to USB PD, other protocols are also supported. Use the button to switch between voltages. If the LED next to a voltage is continuously lit, it means that the voltage is supported, if the LED flashes, the voltage is not supported.

The solder pads on the bottom offer various functions when connected:

S1: This can be used to lock a voltage. To set a different voltage, the button must be pressed while connecting to a PD power supply. The voltage can now be changed with the button. To save the desired voltage, the module must be disconnected from the PD power supply and reconnected without pressing the button. Now, the voltage cannot be changed with the button.
F1: The module goes through all PD voltages from high to low and then ends at 5V. All supported PD voltages are then indicated with continuously lit LEDs.
F2: Same as F1, except the module maintains the highest possible PD voltage.
5V, 9V, 12V, 15V, 20V: The module immediately triggers the desired voltage.
PD ONLY: The module only uses the USB PD protocol.
DP, DM: Not used on this variant.

#9 Chirp! Capacitive Soil Moisture Sensor with Cable - I2C

This is the I2C variant of the Chirp! Plant Watering Alarm. This variant has no buzzer, but can be read out via I2C. Examples are available for Arduino and Raspberry Pi, among others.

The sensor differs from other soil moisture sensors by the capacitive measurement instead of a resistive measurement. This makes the sensor a lot more resistant to corrosion and therefore lasts longer.
